# 2026-11-05 · Meshy 模型与全屏滚动体验验收清单

本清单记录本轮新增要求，供模型、前端和测试共同验收。`待验` 表示尚无本轮可复核证明；不能因为旧 v4 已上线、构建成功或自动化通过就标为完成。

## 当前基线与缺口

- 已发布 v4 是 TripoSR 单图重建头部、Blender 分件道具与轻量面部控制，来源见 `scripts/avatar-v4/README.md`；**当前仓库基线不是 Meshy 高质量模型交付证明**。
- v4 的可编辑 Blender、139 节点、两个 morph、道具动作和无损 Meshopt 已有上一轮证明。其正面近景通过，不代表新模型的侧后方、贴图、动作或极近镜头已通过。
- 本轮前端已改为单一固定全屏场景与滚动镜头章节，暂用 v4 接通交互，待本轮自动化和最终模型视觉验收。将画布设成 `100vw` 本身不能证明角色足够巨大。
- 既有四工作项目、旧地址/锚点兼容、文章/小说/视频/资源/后台、移动降级继续作为不可回退的基线。上一轮检查见 `docs/STATUS_2026_11_05_STICKER_WORLD.md`。

本轮前端工程证据（临时 v4 资产）：本机 `http://127.0.0.1:3099` 的 `home.spec.ts` 与 `portfolio.spec.ts` 共 36 项通过（1.9 分钟）。随后按实际预览反馈拉远首屏镜头、下移标题、放大正文与贡献文字，满视口模型投影、滚动相机往返、390px 手机阅读三项定向复测通过；最终类型检查与 lint 通过。截图保存在 `.local/qa-cinema/`，其中 `desktop-intro-1272-final.png`、`desktop-work-1272-final.png`、`mobile-intro-final.png`、`mobile-work-final.png` 是该轮调整后的实拍。以上只证明前端实现与回归；本清单的 Meshy 资产、最终近景美术及最终模型视觉验收仍保持待验。

## 2. Blender 动作、表情与贴图 — 待验

- [ ] 提供可编辑 `.blend`，贴图打包或使用明确可重建的相对路径；导出脚本与节点/morph/动作合同能对应最终 GLB。
- [ ] 头部、双眼、眼睑、嘴部、手与苹果/面包/手机可独立控制；实际导出后仍能定位所需节点与 morph，材质 alpha 不被压缩或导出流程改坏。
- [ ] 本轮动作在 Blender 中有可复核的关键帧、Action/NLA 或明确的程序控制源。若仅有网页 JS 程序动画，应如实标注，不能声称已经交付 Blender 动作片段。
- [ ] 自然、搞怪、惊讶、大笑及眨眼的面部变化在近景中自然可读；检查表情过渡、嘴/牙/舌显隐和极端值穿插。
- [ ] 抛苹果、咬面包、手机闪光与手部运动同步；动作结束和重置恢复正确状态，快速连续点击不会漏动作或留下错误显隐。
- [ ] 最终贴图保留细节与透明边缘；压缩前后比较眼睑、贴纸白边、发丝与文字。无损 Meshopt 可保留二进制，但不能修复原始贴图质量。

## 4. 真实滚动镜头 — 已实现并验证

- [x] 仅滚动页面，就能推进实际 Three.js camera 的位置、焦点/目标或镜头构图；不能用 DOM 位移、文字切换或自转假装镜头运动。
- [x] 多个故事章节各有明确镜头；正向滚动、反向滚动、直接 hash、Back/Forward 均能回到正确章节和可读位置。
- [x] 点击六个领域入口滚动到对应章节；既有工作入口、四项目详情、旧 hash 和 308 兼容继续有效。
- [x] `data-camera-*`、`data-camera-target-*` 来自实际 camera / look-at 状态；`data-scroll-progress`、`data-shot`、`data-story-index` 供行为定位，不能将目标值冒充实际相机值。
- [x] 自动化固定领域选择与指针，滚到两个不同章节后比较实际相机坐标；排除呼吸、自动眨眼或点击导致的变化假阳性。
- [x] `prefers-reduced-motion` 下镜头可直接切换到稳定构图，停止无关漂浮/眼神追随，导航与阅读仍完整。
