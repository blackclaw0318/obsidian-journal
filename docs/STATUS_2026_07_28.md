## 6. 工程关键教训 (✅ 已入 MEMORY)

- ⚠️ Edge Runtime middleware 不能直接 sqlite — fire-and-forget fetch 推 Node Runtime API
- ⚠️ DB row 传给 client component 必须 serializeForClient (Sparkline 触发 500)
- ⚠️ middleware 的 fetch 用 x-forwarded-host/proto, 不用 req.url (cloudflared 后取到内部 URL)
- ⚠️ '用户面' vs 'admin 内部' 是两个不同语义层 (dedup 合理性不一样)
- ✅ '一次性拍 Q1-Q4 再干' 防 3 轮不愉快
