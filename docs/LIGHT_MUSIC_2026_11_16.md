## 已实现

音乐页 `/music` 保留三首原创作品；`/music?library=light` 提供 Light 曲库。两类切换时会卸载原播放器，防止叠播。

Light 曲库按颂赞、悔改认罪、奉献、爱慕、祷告祈求、感恩、节期、激励、福音性、纪念、其他筛选，并支持歌名和作者搜索。每首歌曲保存分类依据。完整歌曲按歌名去重，保留多份谱源；残页记录不增加歌曲数量。

界面沿用现有米白纸感、鼠尾草绿、陶土色及线框风格，支持窄屏和深色主题。桌面左侧为可滚动分类歌单，右侧为播放器和曲谱。

当前资源清点（首批上线范围）：

- 89 首去重歌曲；64 首提供 MP3，其中 53 首检查了 MP3 文件头与完整文件长度，另 11 首来自小羊诗歌官网公开地址，仍需逐首试听。
- 7 首具备站内完整吉他谱及钢琴双手编配：《脚步》《安静》《和散那》《奇异恩典》《每一次我赞美主》《以便以谢》《充满我》。包含旋律、歌词、节奏、和弦、吉他六线谱和钢琴左手实际伴奏音符；谱面同步转调。钢琴左手是 Light 分解和弦编配，并非原版钢琴录音扒谱。
- 其余 82 首未标为完整转调谱。保留已找到的外部 PDF、图片、曲谱页面以及明确标注的和弦参考。85 首关联具体谱本，总计 96 个公开谱源链接。
- 吉他支持半音升降、目标调、变调夹、字号与六线谱；钢琴保持实际演唱调，不受变调夹影响。弱起、三连音、一二房结尾以及每个系统的左右手小节时值有回归测试。
- 原始图片未上传，公开内容仅包含歌曲元数据、公开音源链接以及整理后的音符文本。
- 手机上谱面保持可读音符大小，整行可横向滑动；原始 PDF 可在页内查看，并保留打开来源的备用入口。
- 页面提供“完整转调谱”筛选和可下载待补清单，CSV 可填写补充链接。

## 待补资源与首批发布决定

用户于本轮明确同意：找不到的部分可以先保留，先上线已找到内容，并记录清单。因此此版本是分批发布，不代表 89 首资源全部齐全。

- 25 首缺可用 MP3 单曲；另有 11 首官方链接待逐首试听。
- 82 首仍缺本站完整转调吉他谱和钢琴双手编配，已有参考谱与来源链接分别保留。
- [完整资源清单 CSV](../public/music/light-resource-checklist.csv) 逐首列明歌曲、类别、音源地址、验证状态、两类完整谱状态及已有谱源，并提供“待补链接”填写列。
- 本机离线识谱生成的其他草稿未作为成品发布；自动转写不能替代人工音高校对。
- 有谱么没有公开可集成 API；曾返回访问频率限制，未绕过限制或保存账户会话。
- 部分公开 CDN 返回 432 字节静音占位 MP3。已从歌单剔除，并增加最小完整文件长度、真实 MPEG 帧头／ID3 及 MIME 类型验证，防止仅凭 HTTP 206 判定音源可用。
- 生产按现有 Docker Compose 使用版本镜像切换；保留数据卷、附件卷与原环境文件，不运行数据库迁移，不启用旧 systemd 服务。

## 检查与复现

在 `/opt/project-deployment/deploy` 使用：

```sh
docker compose -f homepage.dev.yaml run --rm --no-deps web npx vitest run tests/unit/light-music tests/unit/music-library.test.tsx
docker compose -f homepage.dev.yaml run --rm --no-deps web npm run typecheck
docker compose -f homepage.dev.yaml run --rm --no-deps -v /app/.next -e NODE_ENV=production -e DATABASE_URL=file:/tmp/light-build.db web sh -ec 'npm run db:init && npm run build'
```

构建使用独立的容器临时 `.next` 卷和空数据库，可保持试听预览运行。不要使用开发环境 `NODE_ENV` 或生产数据库进行构建；不要同时让开发进程写同一个 `.next`。

验证通过：16 项测试（含全部参考和弦音高检查和原音乐页回归）及 TypeScript 类型检查。

上一阶段构建通过：73 个页面完成生成，使用临时构建数据库。本轮发布镜像的构建与验收结果见后续发布记录。窄屏 390 px 与 320 px 无横向溢出；已核对演唱 C→D、吉他夹 2 品后钢琴保持 D 调、原创三首播放器切换及其他类 3 份残谱。

公开 MP3 的复核脚本为 `scripts/light-music/check-audio.mts`，只读取传入的 URL 清单并输出检查报告，不下载或代理整首音频。

用户在浏览器实际播放《安静》，于本轮明确确认已经听到音频。其余音源的 Range 核验不能替代逐首出声验收。

预览使用独立端口 23003，验收后按容器约定停止开发服务。截图与本地验收记录保存在 `.local/light-music/`。
