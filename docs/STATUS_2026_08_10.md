## 🔒 关键工程教训 (本次 commit)

1. **Nav 桌面端用 `slice(0, 5)`** — 加新菜单必须同步改 slice, 否则只在移动端可见
2. **新功能用独立分支隔离 WIP** — main 有 4 M + 3 ?? 未拍, 直接在 main 上做 v0.43 会污染
3. **每次提交前 `npx tsc --noEmit`** — TypeScript clean 是底线
4. **SSR HTML 检查比 E2E 截图快 10 倍** — 11 项 grep 检查 1 秒搞定, 截图 30 秒+
5. **JSON-LD schema 必加** — 落地页 SEO 友好, Quiz schema 有助 Google 富文本展示
6. **C 路线 (文档公仓 + 代码私仓)** — 老板的 obsidian-journal 主站 + 独立的 psych-quiz-bot 公仓 reference, 双赢
