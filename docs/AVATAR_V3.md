# 上坤虚拟形象 v3

## 当前实现

页面加载 `public/models/avatar-v3.glb`，6,591,184 字节、158,483 个三角面。角色保留用户参考中的辫发、耳饰、灰色 Polo、苹果、吐司和手机，使用更动漫的外观与哑光材质。眼距沿用上一聊天最后调整后的 v3 原稿。

该文件包含真实三维网格，以及独立的眼白、虹膜、瞳孔和眼睑。`PortfolioScene` 用 Three.js 渲染；指针在整个页面移动时，独立旋转眼球，头部只做轻微跟随；拖动可改变角色角度，重置按钮归正视角与眼神。

自然、眨眼、思考使用眼球/眼睑变换，不切换平面表情图片。自然状态定时眨眼，思考状态在指针离开时改变视线；项目滚动和筛选同步改变角色状态、舞台颜色和当前项目名称。手机端复用同一个场景，将舞台缩为悬停卡片。

## 资源来源与限制

v3 概念图由上一聊天使用内置 image generation 工具，基于用户原始虚拟形象生成。网格沿用官方 TripoSR 权重的本机 Apple MPS 单图重建，再经 Blender 简化、纹理投射和眼部几何处理。MIT 许可证在 `public/models/LICENSE-TripoSR.txt`。

本轮未重新生成或修改概念图。眼睑改为贴脸曲面、顶点透明渐隐边缘；仅眼睑使用 unlit 材质，主体与眼球为 roughness=1、metalness=0、specular=0 的哑光 PBR 材质。原始输入、模型工作室和生成脚本未进入公开仓库。

这仍是单视图重建，不是完整人工雕刻或面部骨骼绑定。侧后方、细辫和道具边缘为推断几何，页面限制在正面附近约 ±9° 的角度；眼睑属于轻量覆盖式动画。无 WebGL、模型失败或上下文丢失时显示 v3 静态备用图，项目内容照常阅读，表情与视角按钮禁用。

## 节点与运行时

- `GazeLeft/Right`：`rotation.y` 为水平视线（约 ±.20 rad），`rotation.x` 为垂直视线（约 ±.12 rad）。
- `LidLeft/Right`：`scale.y` 为绝对开合量 `.001–1`；小于 `.01` 时隐藏，避免压扁后残留细线。
- `WinkCreaseLeft/Right`：接近闭合时显示眼睑弧线。
- 不要将 v2 的写实表情贴图用于 v3；保留眼睑材质的透明度和顶点颜色。
- 前 +Z、上 +Y；加载时归一化高度为 3.35，自动按画布比例容纳角色。
- 帧率上限约 30fps，离屏及后台停止绘制；减少动态效果偏好下停止指针跟随、浮动和自动眨眼。
- 卸载时释放几何、材质、全部贴图、监听器与画布；WebGL 上下文恢复后重新显示场景。

## 验证入口

`tests/e2e/portfolio.spec.ts` 覆盖眼球左右跟随、拖动和重置、手机时间线联动、项目详情返回以及无 WebGL 阅读。画布容器的 `data-gaze-x/y` 来自实际眼球节点旋转，`data-view-yaw` 来自主体旋转，供验收区分眼神与头部运动。
